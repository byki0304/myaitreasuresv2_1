# 나의 AI 총무 · My AI Treasures

여러 사람이 대신 결제한 모임 비용을 **지출별 부담 참여자끼리만** 공정하게 나누고, 누가 누구에게 얼마를 보내면 되는지 알려 주는 단일 HTML 정산 도우미입니다. 로그인·서버·외부 라이브러리 없이 브라우저에서 바로 동작합니다.

- 배포: [https://myaitreasuresv21.vercel.app/](https://myaitreasuresv21.vercel.app/) (Vercel) · [GitHub Pages](https://byki0304.github.io/myaitreasuresv2_1/)
- 언어: 한국어(기본) · English · 日本語
- 통화: 원화 KRW(기본) · 달러 USD · 엔화 JPY — 통화를 바꾸면 단위만 바뀌고 금액은 환산되지 않습니다.

## 주요 기능

- 모임 정보, 참여자, 지출(내역·금액·세금 옵션·결제자·부담 참여자) 입력과 즉시 검증
- 세금 옵션: 세금기포함 / 10%·5%·1% 추가 (반올림)
- 지출별 균등 분담, 나누어떨어지지 않는 나머지는 등록 순서대로 1씩(USD는 0.01달러씩) 추가 부담
- 사람별 요약, 개인 송금 안내, 전체 송금 목록, 정산 내용 복사, 사람별 메시지 작성
- 입력 화면의 '새 정산' 버튼(사이드바와 동일 기능)
- 데스크톱·모바일 가로·모바일 세로 화면 대응
- 설치형 웹앱(PWA): 모바일 홈 화면/데스크톱에 설치, 오프라인 실행

## 실행 방법

- 웹: 위 배포 주소에 접속 (설치는 주소창의 설치 버튼 또는 모바일 '홈 화면에 추가')
- 로컬: `index.html`을 브라우저로 바로 열기, 또는 `python -m http.server 8080` 후 `http://localhost:8080/` (서비스 워커·설치 기능은 http(s)에서만 동작)

## 파일 구성

```
├── index.html              # 앱 전체 (HTML·CSS·JS 단일 파일)
├── manifest.webmanifest    # 설치형 웹앱 설정 (이름, 아이콘, 테마 색)
├── sw.js                   # 서비스 워커 (오프라인 캐시)
├── icons/                  # 앱 아이콘 (SVG 원본, PNG 192/512, maskable, apple-touch, favicon)
├── .github/workflows/      # GitHub Pages 자동 배포
└── .nojekyll
```

## 테스트 결과 (배포본 기준, 2026-11-08)

같은 시나리오(참여자 A·B·C, 식사 1,000+10%·간식 500+5%·물품 101+1%, 결제자 A·B·C, USD는 10·5.00·1.01)를 **3개 언어 × 3개 통화 = 9가지 조합** 모두에서 자동 테스트했습니다.

| 통화 | 총지출 | 송금 | 결과 |

| KRW | 1,727원 | B → A 51원, C → A 473원 | 통과 (ko·en·ja) |
| USD | 17.27달러 / $17.27 / 17.27ドル | B → A 0.51, C → A 4.73 | 통과 (ko·en·ja) |
| JPY | 1,727엔 / 1,727 yen / 1,727円 | B → A 51, C → A 473 | 통과 (ko·en·ja) |

- 결과 화면·복사 텍스트·메시지·개인 안내의 금액 표기, 번역 키 누락 없음(언어별 162개 동일)
- 입력 검증: 빈 값, 중복 이름, KRW/JPY 소수 거부, USD 소수 셋째 자리 거부, 음수·최대값 초과 거부
- 흐름: 언어 전환 시 입력 유지, 새 정산(확인 후 초기화·언어 유지), 처음으로 이동
- 360px 모바일에서 입력·결과 화면 가로 넘침 없음, 첫 화면은 데스크톱·가로·세로 모두 한 화면에 맞춤
- PWA: 서비스 워커 활성화, 매니페스트 오류 없음, 설치 가능, 아이콘 파일 200 응답, JS 오류 0건
